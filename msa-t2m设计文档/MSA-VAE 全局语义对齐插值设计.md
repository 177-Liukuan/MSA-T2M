# MSA-VAE 全局语义对齐插值设计

## 1. 核心痛点：时序裁剪导致的语义错位 (Temporal Crop Semantic Mismatch)

在 MSA-VAE 的训练过程中，为了适应底层 Causal CNN 和 Transformer 的固定输入维度，数据加载器（DataLoader）会从长视频序列（例如 300 帧）中随机裁剪出固定长度（如 64 帧）的滑动窗口。

- **全局文本的静态性**：全局文本描述（如 HumanML3D 的 Caption）通常概括了整个 300 帧的完整动作流（例如：“一个人上楼梯，转身，然后下楼梯”）。
- **语义错位悖论**：当滑窗仅截取到中间的“转身”部分时，如果强行要求 Transformer 输出的全局 `[CLS]` Token 与完整的全局文本 CLIP 向量对齐，模型会被迫在仅有“转身”的物理特征中去凭空寻找“上下楼梯”的特征，导致对齐目标的严重失真。

## 2. 设计哲学：隐式的潜空间注意力机制 (Latent Space Attention)

受 MotionCLIP 潜空间算术（Latent Space Arithmetic）和运动可编辑性特性的启发，CLIP 的高维语义空间支持向量级别的线性和逻辑叠加。

与其直接丢弃全局标签，不如构建一种**“在全局背景下高亮局部”**的机制：

- **不抹除未发生的动作**：保留原始的全局文本特征作为“舞台背景（Stage Background）”，让模型依然能够感知到当前动作是某个宏大叙事（如完整的上下楼梯过程）的一部分。
- **局部特征的聚光灯（Spotlight）**：将当前 64 帧窗口对应的局部文本（BABEL）特征作为“聚光灯”，在潜空间中打在全局背景上。这相当于明确告诉模型：“虽然大背景是上下楼梯，但请你把视觉重心死死锁定在**转身**这个局部动作上。”

## 3. 数学与工程实现：带边界约束的归一化插值 (Normalized Interpolation)

为了保证合成特征的数值稳定并严格约束在 CLIP 单位超球面上，采用线性插值近似球面插值的计算管线：

**步骤 1：局部语义坍缩 (Local Semantic Pooling)**

将当前 64 帧窗口内的局部 CLIP 特征（64帧对应64个512维clip特征）沿时间轴进行平均池化（Mean Pooling），提炼出当前窗口唯一的确定性局部语义向量 $L_{pooled}$。

**步骤 2：引入插值权重因子 (Interpolation Weight Factor $\alpha$)**

设定限制在 $[0, 1]$ 范围内的超参数 $\alpha$（可设为定值或动态比例 $\frac{window\_size}{total\_frames}$），用于精准控制局部特征的融合比例。$\alpha$ 越大，局部动作的高亮效应越强。

**步骤 3：语义线性插值 (Semantic Interpolation)**

对原始全局文本向量 $G_{origin}$ 与局部向量 $L_{pooled}$ 进行按比例加权融合，平滑转移语义重心：

$$G_{mixed} = (1-\alpha)G_{origin} + \alpha L_{pooled}$$

**步骤 4：单位超球面重投影 (L2 Normalization)**

对插值后的向量进行 L2 归一化，彻底消除特征范数漂移，使其精确投影回 CLIP 空间的单位超球面表面，得到最终的动态全局标签：

$$G_{target} = \frac{G_{mixed}}{||G_{mixed}||_2}$$

## 4. 预期的核心收益

1. **动态上下文标签**：同一个全局文本（如“上楼+转身+下楼”），随着滑动窗口位置的不同，其全局对齐目标 $G_{target}$ 会在潜空间中发生动态漂移。滑到开头时，它是一个“侧重上楼的完整动作”；滑到中间时，变成“侧重转身的完整动作”。
2. **缓解对齐压力，提升表征质量**：模型在做 Global Align 时，不再被不合理的静态标签“逼疯”，能够更从容地从当前物理潜变量中提取对应的高亮语义，同时又保留了对长程上下文的感知能力。
